## MCP Usage

Use [grayhaven-mcp-icon.svg](../icons/svg/grayhaven-mcp-icon.svg) for the
Grayhaven Systems LLC MCP connection.

The MCP icon uses the canonical monogram with its filled circular background
and transparent corners. Use it as-is without cropping the circular border or
mark.

## File Formats

SVG should be used where possible.

Use PNG for platforms that do not support SVG uploads.

For MCP icon uploads, the PNG must be at least 256x256 pixels and no larger
than 10 KB.
