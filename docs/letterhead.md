# Letterhead

[Back to README](../README.md)

This document defines the basic letterhead layout for written business
correspondence from Grayhaven Systems LLC. It is a visual and typographic
specification; individual document tools may implement the layout using their
own page and paragraph controls.

## Page and identity block

- Use the light-background Grayhaven Systems LLC wordmark on a white
  background.
- Keep the wordmark left aligned and size it proportionally so it is clearly
  visible without dominating the page.
- Place a right-aligned identity block on the same horizontal line as the
  wordmark.
- The identity block contains, in order:
  1. **Grayhaven Systems LLC**
  2. `Practical infrastructure automation,`
  3. `modernization, and cloud migration`
  4. `grayhavensystems.com`
- Place a horizontal divider below the identity block and wordmark. Use the
  primary Grayhaven blue, `#58ACE0`.

## Typography and colors

- Use Arial throughout the letterhead.
- Regular correspondence text uses 10.5 pt Arial.
- **Grayhaven Systems LLC** in the identity block uses 10.5 pt Arial bold.
- The two tagline lines use 8.5 pt Arial in gray `#5C5958`.
- `grayhavensystems.com` uses 8.5 pt Arial in blue `#179FD9`.
- Use dark text `#1C1F24` for regular black text and bold labels.
- Use italics only where specified below; regular correspondence text should
  not be italicized.

## Content order and spacing

Use clear vertical separation between each major correspondence block. A
typical starting point is 18–24 pt of space between blocks, with tighter line
spacing within multi-line address and signature blocks. Adjust only as needed
to keep the page balanced and readable.

The recommended order is:

1. Date line
2. Recipient block
3. Subject line
4. Salutation
5. Body text
6. Closing
7. Signature block

## Correspondence structure

### Date line

Use a regular, non-italicized date line.

### Recipient block

Use the following order with regular, non-italicized text:

- Recipient name in bold
- Recipient title
- Organization
- Street address
- City, state, and ZIP code

### Subject line

Use **Subject:** in bold, followed by the subject value in italics on the same
line.

### Salutation

Use the recipient's name followed by a comma, for example:

`[Recipient Name],`

### Body

Use regular, non-italicized 10.5 pt Arial for the body text. Separate
paragraphs with enough vertical space to make the correspondence easy to
read.

### Closing

Use:

`Sincerely,`

### Signature block

Leave appropriate space for a handwritten or digital signature, followed by:

- Signer's name in bold
- Signer's title
- `Grayhaven Systems LLC`
