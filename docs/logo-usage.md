# Logo Usage

[Return to README](../README.md)

Grayhaven currently uses a wordmark and a circular monogram/profile mark.

The logo direction is accepted, but the assets require context-aware use. The
wordmark needs separate light-background and dark-background variants because
the graphite parts of the mark can lose contrast on dark surfaces.

## Wordmark Variants

Use [grayhaven-logo-wordmark-light.svg](../logo/svg/grayhaven-logo-wordmark-light.svg)
on light backgrounds.

Use [grayhaven-logo-wordmark-dark.svg](../logo/svg/grayhaven-logo-wordmark-dark.svg)
on dark graphite, gunmetal, or space-gray backgrounds.

The dark-background wordmark uses:

- Soft White wordmark text: `#E6EAF0`
- Brightened graphite mark gradient: `#5D6874` to `#3B4651`
- Divider/support marks: `#444C56`

Do not use the light-background wordmark directly on dark surfaces unless the
surface behind the logo is intentionally light.

## Monogram/Profile Logo

Use [grayhaven-logo-monogram.svg](../logo/svg/grayhaven-logo-monogram.svg) as
the canonical profile mark.

The monogram/profile logo carries its own filled circular background and can be
used on light or dark surfaces. It is suitable for profile pictures, avatars,
favicon exploration, Discord profile images, Reddit profile images, and compact
brand contexts.

The monogram/profile logo should normally be used as-is. Do not crop it into a
square that cuts off the circular border or mark.

## SVG and PNG

Prefer SVG for web/content usage when supported.

Use PNG for platforms that do not support SVG uploads. PNG files are rendered
with transparent backgrounds where appropriate:

- Wordmarks have transparent backgrounds.
- The monogram/profile asset has transparent corners and a filled circular
  background.
